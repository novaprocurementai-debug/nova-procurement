مسار الشراء المؤسسي

من طلب الاحتياج إلى التوريد والتدقيق.

1. تحديد الاحتياج والميزانية

تسجيل المنتج والكمية والوجهة ومتطلبات الامتثال.

2. طلب عروض ومقارنة موثقة

مقارنة السعر والحد الأدنى والمهلة والشحن والأدلة المتاحة.

3. مراجعة واعتماد أمر الشراء

تحتاج الموافقات متعددة المستويات وسجل التدقيق إلى تفعيل الخادم والصلاحيات.

4. متابعة التنفيذ والفواتير

لا يُعد التتبع أو الدفع حقيقياً إلا عند ربط مزود الخدمة المناسب.

السوق العالمي

اكتشاف المنتجات والموردين عبر قطاعات ودول متعددة.

المصانع والموردون

اكتشف المصنعين والمصدرين وتحقق من الأدلة قبل التعاقد.

شارة التحقق لا تُمنح إلا عند وجود إجراء تحقق حقيقي. نتائج البحث ليست ضماناً لجودة المورد أو صحة شهاداته.

طلب عروض الأسعار RFQ

أنشئ طلباً منظماً لمقارنته مع عروض الموردين.

الحفظ المحلي لا يعني أن الطلب أُرسل إلى موردين. الإرسال الفعلي يتطلب تفعيل نقطة API وتكامل مراسلة.

طلباتك المسجلة

مقارنة العروض

أدخل الأسعار والمهل والشحن لاتخاذ قرار شراء أوضح.

مساعد التفاوض

حضّر عرضاً مقابلاً وشروطاً تفاوضية واقعية.

الزراعة والمواد الخام

المحاصيل، الحبوب، الأسمدة، المواد الأولية والمعدات الزراعية.

العقارات التجارية

مصانع ومستودعات وأراضٍ تجارية ومحلات ومكاتب للبيع أو الإيجار.

يمكن إدخال أي ميزانية أو تركها فارغة. هذه الواجهة لا تدّعي أن العقارات معروضة فعلياً إلا إذا زُوّدت بقاعدة بيانات أو API للعقارات.

النقل والشحن العالمي

خطط للشحن البحري والجوي والسككي والبري.

جداول السفن والرحلات ومواقعها الحالية لا تُعرض كبيانات حية إلا بعد ربط مزود بيانات معتمد. لا تعتبر نتائج هذا النموذج حجزاً مؤكداً.

تتبع الشحنات

تحقق من حالة الشحنة عند توفر تكامل الناقل.

حاسبة التكلفة الواصلة

قدّر تكلفة المنتج حتى وجهة الاستلام، مع إظهار البنود المدخلة.

الحساب تقديري حسب القيم التي تدخلها، ولا يستبدل التعرفة الجمركية الرسمية أو عرض الشحن الملزم.

أوامر الشراء

سجل مسودات أوامر الشراء وراجعها قبل الاعتماد.

العقود والموافقات

سجل مرجعي للمراجعات ومسارات الاعتماد.

هذا سجل واجهة محلية؛ لا يطبق وحده فصل الصلاحيات أو التوقيع الإلكتروني أو الموافقات القانونية الملزمة.

الفواتير والميزانية

سجل الفواتير ومقارنة المبالغ بأوامر الشراء يدوياً.

مطابقة الفاتورة مع أمر الشراء والاستلام (3-way match) تتطلب سجلات استلام وصلاحيات وخادماً موثوقاً؛ إدخال هذه البيانات هنا ليس تحققاً محاسبياً آلياً.

إدارة الموردين

قائمة الموردين التي أضفتها محلياً إلى المقارنة.

لا ترفع مستندات مصرفية أو كلمات مرور أو بيانات حساسة إلى نموذج غير موصول بخادم آمن.

الاشتراكات والرسوم

تصور أولي لخطط الاستخدام؛ الأسعار التالية أمثلة قابلة للتغيير وليست خطط دفع مفعّلة.
